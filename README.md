# Amazon Clone

A responsive front-end clone of the Amazon homepage built using HTML5 and CSS3. This project recreates the overall layout and design of Amazon, including the navigation bar, search bar, hero section, product cards, and footer. It was created to practice HTML, CSS, Flexbox, responsive web design, and front-end development concepts.

## Technologies Used
- HTML5
- CSS3

## Features
- Responsive homepage layout
- Amazon-inspired navigation bar
- Search bar UI
- Hero banner section
- Product category cards
- Multi-column footer
- Clean and organized code structure
